# 经历：全景线稿与实体拼合

## 内容与构图

- 共七幕：大学、投资研究、期货、数据自动化、创意自动化、AI 产品、AI 金融创业。
- 保留 `careerArchive.ts`、`education.ts` 和 `experience.ts` 的全部可见原文及项目链接，仍为 23 个阅读部分。
- 每幕是一幅延伸到屏幕四边的线稿环境。彩色物体沿自然轮廓独立飞入，文字嵌在一张空白的奶油色撕纸上，整张纸作为另一块拼片飞入。
- 网页文字使用 HTML；插画不包含文案。桌面纸卡居左，手机纸卡靠下，线稿在纸卡四周连续可见。
- 七组线稿与透明物体共 14 张 WebP，位于 `public/career-panorama/`。生成方式、提示词及素材表见 [career-panorama-prompts.md](career-panorama-prompts.md)。

## 图层结构

`src/lib/career/artwork.ts` 定义每幕三组物体的选区。选区作用于已经透明的物体图，实际轮廓由透明通道决定。

1. 纸色底。
2. 全屏线稿，使用物体透明通道的补集蒙版。
3. 三组对应的局部线稿，开场与背景共同还原完整手绘环境。
4. 三组彩色透明物体，从下方错时飞入。
5. 文字撕纸：空白纸面、标题、正文和阅读进度作为同一组移动。

每个彩色拼片的外侧使用 `CareerPaperEdge.tsx` 添加奶白色撕纸背衬：由裁切后的透明轮廓外扩约 7px，经固定种子的粗细两层扰动生成厚薄不均的毛边，叠加纸纤维色差和 1.5px 的轻微厚度阴影。滤镜只处理背衬，原图以原坐标覆盖在最上面；边缘随拼片一起飞入，不单独运动，也不跟随鼠标。七幕共 21 组拼片复用此效果，无需新增位图素材。

`CareerTextPaper.tsx` 给七张文字纸提供不规则撕裂轮廓、空白纸面和轻纸纹，并复用拼片的毛边。文字保留为可选择、可访问的 HTML，纸面滤镜不会扭曲字形。移除旧矩形卡片的边框和大面积投影；纸张形状向内容区外扩，阅读留白仍由原布局控制。

物体落位时，其对应局部线稿渐隐。所有图层使用同一坐标与覆盖尺寸，落位后保持零平移、零旋转，与底图固定对齐。窄屏裁切聚焦右侧主体，不重新拉伸单个拼片。

## 滚动编排

`src/lib/career/choreography.ts` 中的距离以舞台屏高为单位：

| 阶段 | 滚动区间 |
| --- | --- |
| 背景淡入 | 0–0.55，第一幕在破洞后已显露 |
| 第一组物体飞入 | 0.30–1.18 |
| 第二组物体飞入 | 0.48–1.36 |
| 第三组物体飞入 | 0.68–1.54 |
| 文字撕纸整体飞入 | 0.90–1.62，纸张和文字一起从屏幕下方移动并轻微旋正 |
| 正文开始 | 1.65，每部分留 1.05 屏 |
| 整幕退场 | 阅读结束后 0.9 屏 |

前幕背景和物体整体淡出，后幕背景接续出现，再飞入新的物体。最后一幕交给原有探索转场。

动画进度由滚动位置直接求值，正向、反向和跳转均可复现同一状态。保留三组物体错时飞入；落位后取消鼠标跟随及阅读阶段的滚动漂移，直到随整幕一起淡出。反向滚回入场区间时按原路径退出。

文字撕纸落位后也归零平移和旋转，阅读翻页时纸张保持固定；整幕退场时纸和文字同步消失。

## 阅读与回退

- 点击或键盘操作纸卡底部短线可跳到对应正文。
- 纸卡高度按最长正文测量；字体加载和视口变化时重新计算。
- 短屏中的长正文可在纸卡内滚动，到达边界后继续页面滚动。
- 系统减少动态效果或屏高小于 640px 时，取消固定滚动舞台，全部正文正常排版。
- `#career` 在增强布局和加载完成后对齐阅读位置，避免刷新后停在半截拼合状态。
- 晶石破洞的画面采样改为全幅校园线稿，避免提前显示尚未飞入的彩色主体。

# 探索页：白色留边、固定斜线与彩色透镜

- 作品 / 技能画面保留原来的实例和相机。Canvas 2D 在它们上面绘制白色留边、1px 内框与 1px 黑色斜直线。桌面下端落在底边宽度的 20% 处，上端落在顶边宽度的 80% 处，两端分别距左 / 右边约五分之一。手机（宽度小于 800px）改为上下分区，直线连接左边高度 60% 和右边高度 40% 的位置，两端高差为内框高度的五分之一；左上为作品、右下为技能。
- 内框到左侧导航的留白与右侧留白相等；手机避开顶部 41px 导航。标题向框内收：桌面距内框 40–88px、手机 28–44px；字号用 clamp 自适应，桌面 64–84px、手机 48–58px，沿用无圆点的横线。
- “作品”的标题、箭头和细线以白色为底色，在独立入口层使用 difference 混合，深色画面上显亮、浅色画面上显暗；取消原来的白色模糊阴影。“技能”保持白色，避免蓝色画面反相后文字偏黄。混合放在作品裁切按钮的外层，保证可以读取下面的真实场景。
- 对角线、GPU 裁切和两个入口的命中区域共享同一组坐标，框外留白不触发打开。中间分界线笔直且固定，鼠标移入 / 移动不产生扰动，没有星链、发光边或鼠标拖尾；只在页面进入 / 退出时随切换进度移动。
- 展开入口时内框与白边随进度退至屏幕外，返回时恢复。经历到探索改为中央破洞：沿用序章的半径、双尺度噪声、亮边与粒子光效；一个整层裁切同步揭开画面、白边、内框和标题。内部斜线在入场时固定，不再从两角合拢。
- 白色留边复用个人经历的 `createAmbientParticleField`：同样的黑色、细点大小、缓慢漂移与鼠标缓动，桌面全屏分布 100 点、手机 55 点。粒子只绘制在白色留边的镂空裁切区内，实际可见数量随留边面积变化，作品 / 技能画面与标题不叠加黑点。白边展开收起时共用同一组边框坐标，离屏 / 隐藏 / 全屏后停止更新，并支持减少动态效果。
- 目录画面默认黑白，鼠标进入内框后显示圆形彩色透镜：直径随内框宽度在 200–320px 间调整，轮廓 1px，着色边缘柔化 8px；采用指数缓动跟随。两侧最终 Shader 共用 CSS 像素坐标与半径，只切换饱和度，不复制场景或改变采样位置。鼠标离开内框时彩色与轮廓渐隐，白边黑粒子和固定对角线保留。
- 透镜只用于探索目录；打开作品 / 技能时随展开进度恢复完整彩色，返回恢复黑白。触屏可直接点进彩色全屏；减少动态效果时保留静态彩色内容，不启用透镜。联系页没有启用透镜状态，沿用原来的颜色。
- 仅探索边界启用 `BoundaryState.ink`。联系页共用的边界 shader 默认保持原有光效。

## 动画与性能

- Lenis 先更新滚动位置，边界、透镜轮廓、作品与技能在同一 GSAP 时钟读取状态。
- 直线使用两个端点的解析公式；DOM 命中区最多五个顶点，仅尺寸或展开状态变化时重算。
- 透镜按滚动 / 尺寸变化缓存容器位置，指针事件只记录坐标。
- 中央破洞保持 513 个采样；噪声整数格点使用有界缓存，保持原轮廓与反向路径。光效只在 ticker 绘制一次，未变化的轮廓不重复上传。
- 离屏、隐藏标签页、独立游戏和全屏时继续遵守各场景的暂停与释放规则。

# 定版清理与动画优化 · 2026-09-27

## 保留的效果

个人经历白底粒子、紧凑吸顶标题、逐批文字字影；探索白边细框、固定斜线与彩色透镜；中央破洞入场和联系页的波动拼接线。

## 本轮调整

- 删除废弃拼贴图、抽象背景、月面点云、采样脚本与过期设计文档，共 28 个现存文件、6,498,598 字节。提交同时收录此前已删除的旧 SVG、飞行背景与星链实现。历史版本保留在 Git。
- 固定斜线从每帧 513 点采样改为两端点解析式。两个命中区各最多 5 点，尺寸或展开进度变化时才重算；GPU 不再上传固定轮廓纹理。冻结 / 减少动态效果时停止重复绘制白边。
- 作品渲染从独立 RAF 迁到 GSAP ticker，与透镜轮廓、技能使用同一时钟；Lenis 在渲染前更新滚动状态。透镜指针事件只保存坐标，滚动或尺寸变化后才读取容器位置。
- 按已安装 Lenis README 的 GSAP 集成方式关闭 ticker lagSmoothing，避免长帧后导航被拉长。章节定位向上取整到 CSS 像素，确保离开转场终点。
- 合并同一位置的重复滚动发布，移除滚动回调里的光效绘制。四个转场光效 pass 仅在 ticker 执行一次；轮廓与速度纹理仅在变化时上传。
- 破洞噪声使用固定容量的整数格点缓存；去除逐采样临时数组分配。轮廓、噪声公式、采样密度和正反向路径保持一致。
- 章头测量分批读写。文字字形测量按宽高、字体、字距与字体加载版本缓存，重复 ScrollTrigger refresh 不再扫描全部字形；行蒙版的固定位置预计算。
- 联系页提前加载资源，但离屏时停止持续渲染黑洞；转场显露时由 chapter-held 状态唤醒。

## 可复查的验证

```sh
npm run typecheck
npm run build
node scripts/check-career-scenes.mjs
node scripts/check-motion.mjs
```

- 正文检查：7 段经历、45 段原文、原顺序与日期、校园配图、已退役元素不再渲染。
- 动画检查：桌面 / 手机斜线端点，展开时命中区互补且覆盖整个内框，反向恢复，破洞正反向路径一致，透镜布局读取缓存与全屏复位。
- 本机 Node CPU 对照：1280×720、390×844、844×390，各 97 个进度，正反向共 298,566 点，优化前后坐标最大误差为 0。五轮平均每帧轮廓计算中位数从 2.317 ms 降到 1.590 ms，约减少 31%。这是单个 CPU 算法耗时，不是整页 FPS 或所有设备的帧率承诺。
- 浏览器核对：1280×720 透镜跨斜线两侧显色且轮廓对齐，技能全屏后透镜消失、返回目录恢复；经历出口两处末章标题 top 同为 25.234375px，回滚 40px 再前进得到完全相同的路径。390×844 内框分界位于左侧 60% / 右侧 40%，正文重新换行后完整显现，102px 章头避开导航，无横向溢出；联系黑洞和两山正常显露。此次未进行硬件 FPS 基准测试。

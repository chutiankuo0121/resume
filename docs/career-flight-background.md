# 经历页：晶石同款粒子空间

当前阶段只修改背景。学校照片、工作配图、文案与时间轴沿用当前排版；图片点云化与破碎重组留待下一阶段。

## 实现

- 直接读取序章的 `/crystal/particles.bin`，共享 `loadBuffer` 缓存；没有重新生成隧道点位。
- 原始数据共 26,202 点，其中空间粒子 12,000 点。按 `aAmbient` 排除晶石表面点，固定隔点采样，桌面和手机均绘制 6,000 点（50%）。
- 顶点调用序章的 `particleKernel.drawParticle`，片元直接使用 `particleFragment`；圆核、抗锯齿、透视尺寸、三档连续噪声聚散使用同一套代码。
- 视角与尺寸参数沿用序章的 `createCameraRig`、33 度视场角、手机 0.6 尺寸比例。DPR 上限 1.5。
- 原始空间点主要是黑色；经历页单独建立银白亮度属性，保留大小与坐标。不会修改序章和联系页共享的源数据。
- `flight.ts` 让滚动驱动 2.4 世界单位/屏的纵深位移，指数平滑减速；反向滚动恢复空间位置。循环边界淡出后回收，没有额外拖尾或发光。
- 停下滚动后保留晶石原有的缓慢聚散；离屏、隐藏标签页和作品详情打开时暂停 GPU 重绘与噪声计时。
- 深链接、较大的位置跳转、标签恢复直接对齐，避免突然冲刺；经历结束时限制滚动位移，继续使用现有 `.chapter-held` 交接。
- 减少动态效果时只绘制静态粒子。WebGL 或素材加载不可用时保留深色背景，正文始终是 DOM。
- 卸载释放几何、材质、空遮挡纹理、渲染器、观察器、GSAP 回调与事件；异步加载结束前卸载不会遗留 GPU 资源。

## 检查

- `npm run typecheck`
- `npm run build`
- `node scripts/check-career-scenes.mjs`
- `node scripts/check-career-flight.mjs [本地原始 particles.bin 路径]`

粒子检查覆盖 50% 数量、排除模型点、源缓存不被修改、反向滚动、停下减速、刷新率一致性、跳转、交接范围。浏览器仍需验收实际视觉：进入经历页、停下聚散、前后滚动、手机与技能/作品交接。构建和数学测试不替代视觉验收。

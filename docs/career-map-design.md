# 个人经历地图实验

## 版本

- 实验分支：`codex/career-map`。
- 拼贴版基线：`87281b7`，完整保留上一版文案、七幅生成图及拼图动画，便于比较或恢复。
- 本版参考 Chartogne-Taillet 的手绘地图、连续运镜和章节导航形式。所有场景模型由本项目代码生成，未复制其网站模型、贴图或实现。

## 设计

一张连续的纸上地图，七个意象地点依次代表大学、投资研究、期货市场、数据自动化、创作运营、AI 产品和金融创业。建筑群用于表达经历主题，不声称还原实际单位建筑或真实地理位置。

大学使用庭院、双翼教学楼和钟塔；研究馆带穹顶；市场是港口与灯塔；自动化工坊有锯齿屋顶和水轮；创作空间有摄影工作室；产品实验室有信号天线；创业观测站面向海岸。

米白纸底、石墨轮廓、稀疏排线和等高线组成共同风格。选中地点的屋顶逐渐染上主题色，朱红路线记录经过的地点。颜料颗粒仅在运镜途中短暂出现，阅读时归零。

## 交互

- 进入经历页默认总览；自然滚动会依次抵达七个地点。
- 地图标记、底部路线和“全览地图”共用同一导航进度。
- 鼠标拖动调整观察方向，普通悬停有很轻的视差；触摸保留页面原生纵向滚动。
- 阅读完整经历使用原生 dialog，正文全部来自原文数据；滚动详情不推进地图，关闭后保持原位置并恢复键盘焦点。
- 少于 620px 高的窗口和减少动态效果模式使用静态地图、点击选择地点，镜头立即到位。

## 实现

- `src/lib/career/map/stops.ts`：路线节点与滚动阶段。
- `terrain.ts`：起伏地形、平整的建筑地块、田垄、海岸与路径。
- `models.ts`：原创程序化建筑、树木和村落；几何按材质合并，减少绘制调用。
- `materials.ts`：纸色、排线、等高线及轮廓材质。
- `createMapScene.ts`：正交相机、连续插值、投影标记和少量局部颜料。
- `createCareerTimeline.ts`：沿用 GSAP/Lenis 时钟，协调滚动、导航、鼠标和阅读面板。
- `portalArrival.ts`：直接采样当前地图画布，与开场破洞共用真实画面。

仅在地图进入视口附近时持续渲染，隐藏标签页和打开正文时暂停；DPR 限制为 1.6。退出时清理几何、材质、观察器、时钟和事件。WebGL 初始化失败时保留平面地图及完整阅读导航。新增字体随 public/fonts 交付。旧拼贴图不再参与启动预载。
